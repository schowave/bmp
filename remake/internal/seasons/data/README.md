# Real seasons

The data of the real seasons; `mise run remake:seasons-update` adds or
updates seasons (see `remake/README.md`).

- `YYYY-YY.json`: the clubs of a season in the format of `clubs.json`
  (`internal/assets/mana.go`).
- `pic/N.png`: logos of clubs the original does not have, N ≥ 1000; their
  sources and licences are in `../credits/logos.csv`.
